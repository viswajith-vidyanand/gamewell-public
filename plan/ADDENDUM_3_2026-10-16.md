# Addendum 3 to Analysis Plan v1 (2026-10-16)
1. The primary model of Plan v1 was fitted on the Plan v1 cohort (5,076 intervals, 371 participants). Fixed-effects and cluster-robust results were saved before a post-fit scripting error stopped the diagnostics. The reported primary results (b1 = 0.0731 valence points per hour; model 95% CI -0.135 to 0.281; CR2 95% CI -0.143 to 0.289; Addendum 2 category (a)) are those from that fit.
2. To obtain the diagnostics required by Plan v1 section 8, one identical refit of the same specification is permitted: same cohort, same formula, REML, default optimizer, no other changes. Its fixed-effect estimates must match the saved results to within 1e-6; otherwise the refit is reported and the original results stand with the diagnostics marked unavailable.
3. The refit is for diagnostics only and does not replace the original results. The model object from the refit is saved so no further refit is needed.
4. No other model is fitted in this step. Sensitivity analyses (Plan v1 section 7) and the secondary life-satisfaction analysis follow in separate, later steps.
