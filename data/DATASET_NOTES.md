# GameWell analysis-ready daily interval dataset

Build date: 2026-10-15. This report contains aggregate results only.

## Inputs and processing

Inputs are the existing cleaned tables: `survey_daily.csv.gz`, `survey_intake.csv.gz`, `xbox.csv.gz`, and `nintendo.csv.gz`. The raw daily survey file is read only to report its aggregate row count before cleaning; it is not used to reconstruct clean survey records. The project R/Quarto pipeline is not available in this environment (Rscript and Quarto are absent), so this output was generated by the included dependency-free Node script. It does not read or reconstruct raw session logs. It preserves the exclusions already applied to the clean inputs.

Daily responses are paired in the existing clean `wave` order, one row for each adjacent pair of retained responses; missed waves therefore create longer intervals. Timestamp values with explicit offsets are parsed as instants and normalized to UTC. Session ranges remain their cleaned UTC boundaries. Exposure is the overlap of each cleaned session range with the half-open interval [start, end). No participant-specific local conversion is needed for elapsed UTC duration or event-time intersection; the project's local-time helper is used for local calendar aggregation elsewhere.

Xbox and Nintendo minutes are separately unioned within platform. The combined linked-console exposure is the union across both linked platforms, so simultaneous minutes are counted once. The difference between platform sums and the combined union is reported as `concurrent_minutes_removed`. Xbox source rows were already merged, filtered, and overlap-resolved by the documented pipeline; Nintendo rows were already deduplicated, merged, filtered, and subject to its documented limits. This build does not re-clean either platform.

## Aggregate counts

- Daily survey rows: 18829 raw to 16346 clean (2483 fewer after the existing pipeline); 1284 participants and 15062 adjacent clean response pairs.
- Valid UTC interval rows: 15062; invalid/unusable timestamp pairs retained and flagged: 0.
- Exact intake matches among daily participants: 1217; participants with Xbox and/or Nintendo linkage: 488, of whom 419 have at least one valid interval.
- Valid linked-console intervals: 5904 across 419 participants; 343 participants have at least two intervals complete for both outcomes at both endpoints.
- Paired endpoint completeness: affective valence 5774; life satisfaction 5769; both measures 5761. These outcomes are kept separate.
- Valid linked intervals with recorded Xbox sessions: 1470; with recorded Nintendo sessions: 535. These interval counts can overlap.
- Among intervals complete for both outcomes at both endpoints, intervals with no recorded session on the linked consoles: 3804. This status is not assigned to unlinked participants.

## Interpretation and readiness

The interval file reproduces the feasibility counts for the linked-console cohort and outcome-complete pairs. This file contains 15,062 pairs across all clean daily participants; 220 of those pairs have no exact intake match and therefore cannot be linked to platforms. Restricting to exact intake matches leaves 14,842 intervals. Of 488 intake-matched participants with a console link, 419 have at least two clean daily responses and contribute intervals; the remainder have no interval. The earlier 4,752-interval count used an additional 84-day post-intake restriction. This build does not impose that extra restriction because it is not a daily-survey cleaning rule and the clean daily wave sequence is the source of consecutive daily completion intervals. Sorting by clean wave and UTC timestamp produces no nonmonotonic pairs in these data.

A zero exposure means no intersecting cleaned session rows on the participant's linked platform(s), under the study documentation's maximal-coverage-on-linkage assumption. No interval-level platform capture-status field is present, so coverage cannot be independently verified for every interval. Unlinked platforms, missing intake linkage, invalid timestamps, and unusable linked session timestamps remain missing, not zero. Nintendo coverage is restricted to first-party titles. This dataset is suitable for descriptive checks and analytic specification; the documented lack of interval-specific capture flags, long gaps, and potential selection into linkage still require prespecified sensitivity handling before fitting models. No statistical model was fitted.
