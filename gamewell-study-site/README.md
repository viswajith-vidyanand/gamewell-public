# GameWell study site
1. `index.html` is the single scrolling page and loads only local assets.
2. `assets/style.css` and `assets/app.js` contain the responsive visual system and interactions.
3. `assets/data.js` embeds the exact aggregate values and registered claim wording used by the page.
4. `assets/*.svg` and `data/` preserve the provided aggregate figures, CSVs, methods, and analysis plan for download.
5. `NUMBER_MAP.csv` traces displayed numbers to source cells; `MISSING.md` records values intentionally omitted.
